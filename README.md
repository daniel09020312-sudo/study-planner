# 공부방 플래너

친구들, 학급과 함께 쓰는 공유 공부 플래너입니다. 한 파일짜리 HTML 앱이고, 기록은 Firebase Realtime Database로 나눕니다. 한 방에 최대 50명까지 들어올 수 있습니다.

## 배포 (Cloudflare Pages)
- 저장소의 `main` 브랜치, 출력 폴더 `public`, 빌드 명령 없음.
- `public/_headers`가 index.html, sw.js, version.txt를 늘 새로 받게 합니다. 새 판이 배포되면 열려 있는 앱이 저절로 다시 읽습니다.
- 무료 요금제는 한 번에 하나씩 배포하고 한 달 500번까지입니다. 수정은 모아서 한 번에 올리세요.

## Firebase 준비
1. Firebase 콘솔에서 Realtime Database를 만들고 주소(`https://NAME-default-rtdb.REGION.firebasedatabase.app`)를 확인합니다.
2. 방을 처음 만들 때 이 주소를 넣습니다. 이후 친구들은 참여 링크(`사이트#join=NAME.REGION`)와 참여 코드 6자리로 들어옵니다.
3. 규칙은 별도 설정 없이 읽기·쓰기를 열어 두고 씁니다. 주소를 아는 사람은 기록을 읽을 수 있으므로 주소와 초대 링크를 공개 장소에 올리지 마세요.

## 무료 요금제 한도 (Spark)
- 동시 연결 100개: 접속한 기기 하나가 연결 하나입니다. 화면이 120초 넘게 가려지면 연결을 닫고 다시 보면 연결합니다. 50명이 기기 2대씩 동시에 켜면 한도에 닿을 수 있습니다.
- 저장 1GB, 내려받기 월 10GB: 바뀐 것만 받는 방식이고 메시지는 14일만 보관합니다. 설정 > 방에서 이 방 기록 크기와 이번 달 받은 양을 볼 수 있습니다.

## 학급 운영
- 방장: 인원 한꺼번에 추가(설정 > 인원), 공지, 방장 넘기기, 점수 기간과 상품 설정.
- 점수 집계 기간(설정 > 점수 집계 기간): 점수는 시작일부터 보이고, 주간 순위 점수, 배지, 최종 결과는 집계 시작일부터 합산됩니다.
- 이름이 겹치면 추가되지 않으니 이름 뒤에 구분 글자를 붙이세요.
- 사용법은 앱 설정의 "사용법"에 있습니다.

## 알려진 한계
- 비밀번호(PIN)는 가볍게 보호하는 용도이고, 잊으면 방장이 풀어 줍니다. 방장이 잊으면 되돌릴 방법이 없습니다.
- Firebase 규칙이 열려 있어 기술을 아는 사람이 주소를 알면 기록을 바꿀 수 있습니다. 친구와 학급 규모의 신뢰를 전제로 합니다.
- iOS 16.4 미만 등 오래된 브라우저는 화면이 조금 다르게 보일 수 있습니다.
